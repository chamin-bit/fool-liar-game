# 바보 라이어 🤪

링크 하나로 핸드폰에서 바로 하는 온라인 (바보) 라이어 게임.

## 로컬 실행
```
npm install
npm start          # http://localhost:3000
```

## Render 무료 배포
1. 이 폴더를 GitHub 저장소로 올리기
2. https://render.com → New → Blueprint → 저장소 선택 (render.yaml 자동 인식)
3. 배포 끝나면 `https://<이름>.onrender.com` 주소를 카톡방에 공유

무료 플랜은 15분 동안 아무도 안 쓰면 잠들어서, 첫 접속 때 30초쯤 걸릴 수 있어요.
서버가 재시작되면 진행 중이던 방은 사라져요.

## 규칙
- 3~10명. 방장이 카테고리·모드·타이머(힌트/투표/해명)를 정하고 시작
- 일반 모드: 라이어만 제시어를 모름 / 바보 모드: 라이어도 다른 단어를 받아서 본인이 라이어인지 모름
- 힌트 한 바퀴 → 투표(과반이면 조기 종료, 동률이면 재투표) → 지목된 사람 해명 → 찬반 최종 투표
- 라이어가 맞으면 라이어가 정답 맞히기 기회(맞히면 라이어 역전승)
- 합의 실패하면 다음 힌트 라운드, 3라운드까지 못 찾으면 라이어 승리
- 잠수 대비: 방장이 ⋯ 메뉴나 ⏭️ 버튼으로 다음 단계로 넘길 수 있음

## 테스트
```
PORT=3123 node server.js
node test/e2e.js              # 4명 자동 플레이 시나리오
node test/bots.js 방코드 3     # 화면 확인용 봇 3명 입장
```

제시어는 `words.js`에서 추가·수정하면 됩니다.
