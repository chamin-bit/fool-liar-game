# 바보 라이어 🤪

링크 하나로 핸드폰에서 바로 하는 온라인 (바보) 라이어 게임.
배포 주소: https://fool-liar-game.onrender.com

## 로컬 실행
```
npm install
npm start          # http://localhost:3000
```

## 배포 (Render)
GitHub `main` 브랜치에 push하면 Render가 2~3분 안에 자동으로 다시 배포해요.
배포하는 순간 진행 중이던 방은 사라지니, 게임 중엔 올리지 마세요.
무료 플랜은 15분 동안 아무도 안 쓰면 잠들어서 첫 접속이 30초쯤 걸려요.

## 규칙
- 3~10명. 방장이 모드·카테고리(여러 개 선택 가능)·타이머를 정하고 시작
- 일반 모드: 라이어만 제시어를 모름 / 바보 모드: 라이어도 **비슷한 다른 단어**를 받아서 본인이 라이어인지 모름
- 힌트 한 바퀴 → 투표(과반이면 조기 종료, 동률이면 재투표) → 해명 → 찬반 투표
- 라이어가 걸리면 정답 맞히기 기회(맞히면 라이어 역전승)
- 합의 실패 시 다음 라운드, 3라운드까지 못 찾으면 라이어 승리
- 한 방에서 이미 나온 제시어는 그 카테고리를 다 돌 때까지 다시 안 나옴

## 채팅 명령어 (누구나 사용 가능)
| 명령어 | 기능 |
|---|---|
| `/시작` | 게임 시작 (끝난 판이면 같은 설정으로 바로 한 판 더) |
| `/초기화` | 진행 중인 판을 끝내고 대기실로 |
| `/넘기기` | 잠수한 사람 차례·투표 넘기기 |
| `/힌트요약` | 힌트 다시 보기 |
| `/랭킹` | 승률 랭킹 |
| `/명령어` | 도움말 |

## 제시어
- 공개 단어: `words.js` (한 줄 `|` 구분 = 비슷한 단어 묶음, 바보 모드 라이어는 같은 묶음의 다른 단어를 받음)
- 비공개 카테고리(우리끼리 아는 단어): 저장소에 올리지 않음
  - 로컬: `private-words.json` (.gitignore 처리됨)
  - Render: Environment에 `PRIVATE_WORDS` 변수로 같은 JSON을 넣기
  - 형식: `{"카테고리 이름": "단어1,단어2|단어3,단어4,단어5"}`
